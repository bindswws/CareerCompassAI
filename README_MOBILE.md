# Career Compass AI — Mobile/Web App

This is a Progressive Web App (PWA). It can run directly in Chrome/Edge/Safari on a phone or tablet once hosted on an HTTPS web address. No Python, VS Code, or Streamlit is needed on the phone/tablet.

## Use on phone/tablet
1. Host this folder on any HTTPS static web host.
2. Open the URL on the phone/tablet.
3. Use the browser menu → **Add to Home screen** / **Install app**.
4. It opens like an app in standalone mode.

The app contains the same three pathways, real-life visual questions, multi-select Class 12 subjects, university/company logos, and QR codes.
